# v0.1 Foundation

The groundwork every later module builds on: package structure, shared DDIC types, number ranges, application log and continuous integration.

## What is inside

| Area | Objects |
|---|---|
| Packages | `Z_VH_BREW` and 9 subpackages (CORE, MD, MM, IM, PP, QM, SD, FI, AN) |
| Domains with fixed values | `ZVHB_PLANT`, `ZVHB_STORAGE_LOC`, `ZVHB_DISTR_CHANNEL`, `ZVHB_MATERIAL_TYPE` |
| Data elements | 15 shared types: plant, storage location, channel, material type, material, partner, batch, quantity, unit, amount, currency, °Plato, alcohol % vol, percent, description |
| Number ranges | 12 objects `ZVHB_PARTN` ... `ZVHB_DECL`, setup class `ZCL_VHB_SETUP_NUMBER_RANGES`, access via `ZIF_VHB_NUMBER_RANGE` |
| Application log | log object `ZVHB_LOG` with 5 subobjects, wrapper `ZCL_VHB_APP_LOG` over `CL_BALI_LOG` |
| Messages | message classes `ZVHB_CORE`, `ZVHB_MD`, `ZVHB_MM`, `ZVHB_IM`, `ZVHB_PP`, `ZVHB_QM`, `ZVHB_SD`, `ZVHB_FI` |
| Overview | `ZCL_VHB_README`, run with F9 |
| CI | abaplint on every push via GitHub Actions |

## Decisions

- [ADR 1](../adr/0001-subpackages-without-encapsulation.md) Subpackages without package encapsulation
- [ADR 2](../adr/0002-number-ranges.md) One number range object per document type
- [ADR 3](../adr/0003-domains-only-for-fixed-values.md) Domains only where fixed values are needed

## Quality

## How to check

1. Run `ZCL_VHB_SETUP_NUMBER_RANGES` with F9. The console reports the processed objects.
2. Open the Fiori app Application Logs, object `ZVHB_LOG`, subobject `SETUP`: one entry per number range object.
3. Run `ZCL_VHB_README` with F9 for the module overview.
4. Run ABAP Unit on package `Z_VH_BREW_CORE`.
